### 1. 数据正确性修复

**confidence 分布计数（`0f5a356`）：** `getConfidenceDistribution` 窗口函数使用 `COUNT(*) OVER (PARTITION BY confidence)` 统计的是 GROUP BY 结果行数（唯一 rule_id 数），而非引用总数。改为 `SUM(COUNT(*)) OVER` 后，113 → 8761，与实际引用数一致。

## 优化模式总结

本次核心优化模式：**全表 JOIN + GROUP BY → 相关子查询排序 + 逐行索引查询**。

适用条件：
1. 需要从大表（rule_references）聚合统计到小表（sessions/rules_metadata）
2. 只需返回有限行数（有 LIMIT）
3. 有索引支持按外键查找（idx_refs_session, idx_refs_rule）

公式：
```
-- 优化前
SELECT s.*, COUNT(r.id) FROM sessions s LEFT JOIN refs r ON ... GROUP BY s.id LIMIT N

-- 优化后
SELECT s.* FROM sessions s WHERE ... ORDER BY (subquery) LIMIT N;
-- 然后逐行: SELECT COUNT(*) FROM refs WHERE session_id = ?
```
