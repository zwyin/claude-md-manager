## 今日交付

### 1. 会话列表页（新功能）

从零构建完整的会话浏览页面。

**API 端点：** `/api/sessions` 支持 limit/offset 分页、days 时间范围过滤、sort 排序（time/citations/rules/duration）、dir 方向（asc/desc）。服务端计算 duration_sec 字段。

**页面功能：**
- 会话 ID 搜索（客户端过滤）
- 时间范围快捷按钮（7d/30d/90d/全部）
- 四维排序（时间/匹配数/规则数/时长），点击切换升序/降序
- 分页导航（Prev/Next），已国际化
- 每行显示：ID 前8位、时间戳、模型 badge、时长、规则数、匹配数

## 技术细节

**排序架构：** 服务端 SQL 排序，`ORDER BY ${orderCol} ${dir}`，支持 CASE WHEN 计算的 duration_sec 虚拟列。
**响应式策略：** 表格/卡片双布局（`hidden sm:block` / `sm:hidden`），而非 CSS overflow 滚动。
**时长计算：** 统一使用秒为基准单位，API 返回 duration_sec，前端格式化为人类可读格式。
