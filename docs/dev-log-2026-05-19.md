## 今日交付

### 1. MCP Server + Skill（核心新功能）

让 Claude Code CLI 能直接管理系统级 `~/.claude/CLAUDE.md`，不再依赖 Web UI。

**新增文件：**
- `mcp_lib.py` — 业务逻辑层（10 个函数：rule 读写、draft CRUD、validate、publish）
- `mcp_server.py` — FastMCP 入口（10 个 `@mcp.tool` 工具）
- `tests/test_mcp_lib.py` — 29 个单元测试，mcp_lib 100% 行覆盖率
- `~/.claude/skills/claude-md-manager/SKILL.md` — Skill 工作流描述

**工作流：** 用户说"更新系统级 CLAUDE.md" → Skill 触发 → `list_rules` → `get_rule` → `save_draft` → `validate_drafts` → 用户确认 → `publish_drafts`

**注册：** 通过 `claude mcp add --scope user` 全局注册，所有项目可用。与 Web UI 共享同一 SQLite DB 和 rules/ 目录。
