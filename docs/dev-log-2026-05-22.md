### 11. 引用追踪 Phase 2（多源置信度合并）

三层引用追踪架构：

| 层级 | 来源 | 置信度 | 触发方式 |
|------|------|--------|----------|
| MCP 工具 | `mcp_tool` | high | Claude 主动调用 `record_citation` |
| Stop Hook | `hook_stop` | medium | 会话结束扫描最后一轮 |
| PostToolUse | `hook_posttool` | low/medium/high | 每次工具调用后扫描 |

**Stop Hook：** `session-logger.py --event stop` 仅分析最后一轮 assistant 消息，所有匹配标记为 medium 置信度。
**MCP record_citation：** `mcp_lib.record_citation()` 接受 rule_id + matched_keyword，自动生成会话 ID。
**置信度合并：** ON CONFLICT 扩展为同时更新 source 列，高置信度覆盖低置信度。

### 12. 仪表盘/分析页增强

**骨架屏加载：** Dashboard 和 Analytics 页面使用 Skeleton 替代纯 spinner。
**引用 Sparkline：** 冷规则列表每条规则旁显示迷你引用趋势。
**图表标签修复：** Recharts Y 轴动态高度（`Math.max(300, sections.length * 32)`），解决 CJK 文字标签被跳过。
**主题适配：** 图表文字颜色从硬编码 `#d4d4d8` 改为 `chartTheme.mutedForeground`。
**规则详情趋势：** 引用趋势图支持 7d/30d/90d/all 时间范围筛选。

### 13. 版本历史修复（React Error #310）

**根因：** `useMemo`（snapshot 分组）位于 `if (loading) return` 之后，导致 loading→data 状态切换时 hooks 数量不一致（17→18），触发 "Rendered more hooks than during the previous render"。
**修复：** 将 `useMemo` 移到 early return 之前。
**辅助修复：** `RoutedErrorBoundary`（pathname key 重置）+ `async RootLayout`（Next.js 16 兼容）。

> 4 commits, 范围：`5740988` → `a8e6cf3`

### 15. 版本历史页根因修复

React error #310（"Rendered more hooks than during the previous render"）的真正原因是 `useMemo` 放在 `if (loading) return` 之后。loading 时 17 hooks，数据加载完 18 hooks。修复：移到 early return 之前。

### 17. 共现规则

规则详情页新增"共现规则"卡片，展示来自其他章节、在同一会话中频繁一起被引用的规则。SQL 使用 `rule_references` 自连接查找共享 session_id。

### 18. 引用报告导出

`scripts/export-report.py`：生成 Markdown 格式的引用分析报告，包含摘要统计、章节分布、Top 20 规则、冷规则、置信度分布。支持 `--days` 时间范围和 `-o` 文件输出。
