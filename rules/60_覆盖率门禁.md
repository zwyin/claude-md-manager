## 覆盖率门禁（跨项目复用）

两套独立方案，按项目类型选用：

### 个人 Python 项目

Skill：`/setup-coverage-gate`，模板在 `/Users/zhiweiyin/repo_ds1600/coverage-gate-py/`

在任何 Python 项目中调用，自动生成 `scripts/run_coverage.py`（--gate 门禁）+ `docs/testing_policy.md` + 更新 CLAUDE.md 交付门禁。分层目标原则：Models ≥ 90-95%，Services ≥ 80%，API ≥ 70%，Utils ≥ 85%，整体 ≥ 75-95%。

已落地项目：`article_archieve_claude`、`llm-benchmark-claude`。

### 公司多语言项目

策略和工具集在 `/Users/zhiweiyin/repo_ds1600/coverage-gate-corp/`

支持 Java（JaCoCo）、Go（go test -cover）、JS（jest）。统一 JSON 报告格式 + 多服务仪表盘。策略核心：先量不卡 → 增量门禁 → 渐进全量，反"凑数"陷阱，ROI 6 指标可量化追踪。
